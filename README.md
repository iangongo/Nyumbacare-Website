# NyumbaCare Kenya 🌴✨
*Your Space. Exceptional Care.*

Boutique deep cleaning and property care services tailored for luxury coastal villas, private residences, and premium commercial properties along the Kenyan Coast.

---

## 🌟 About the Project
NyumbaCare Kenya delivers elite, detail-oriented cleaning services specializing in delicate coastal materials such as coral stone, terrazzo, and fine glass. This repository contains the source code for the official modern web application, built to provide a cinematic, buttery-smooth user experience.

## ✨ Key Features & Aesthetic
* **Cinematic Design:** Built with a strict, high-contrast luxury palette of absolute black (`#0A0A0A`), crisp white, and vibrant coral-red (`#E63946`).
* **Interactive Services Grid:** Detailed coverage for Post-Construction, Holiday Villa Turnaround, Seasonal Deep Cleaning, and Upholstery Care.
* **4-Stage Process Timeline:** An interactive breakdown guiding clients from Initial Assessment to Project Handover.
* **Built-In Assistant & Quick Actions:** Instant click-to-action routing for WhatsApp bookings, direct email inquiries, and map navigation.
* **Fully Responsive:** Optimized for seamless performance across mobile (Android/iOS) and desktop devices.

## 🛠️ Tech Stack
* **Framework / Build Tool:** Vite, React, TypeScript
* **Styling & Motion:** Tailwind CSS, Lucide Icons
